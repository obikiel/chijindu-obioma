## 2. Logo System

### Primary Logo
`<CEO />` — Code-tag style, rendered in JetBrains Mono Bold.
- Brackets `< />` in Electric Cyan (#00E5FF)
- Letters `CEO` in Cloud White (#E8ECF1)
- Always on dark backgrounds

### Variations
| Variant        | Format                        | Use Case                    |
|----------------|-------------------------------|-----------------------------|
| Full Logo      | `<CEO /> Chijindu Ezekiel Obioma` | Website header, documents  |
| Monogram       | `<CEO />`                     | Social media, favicon       |
| Terminal Mark  | `ceo@infra:~$`                | Blog posts, terminal UIs    |

### Clear Space
Maintain padding equal to the height of the `C` character on all sides.

### Minimum Size
- Digital: 32px height
- Print: 12mm height

### Don'ts
- Never use on light/white backgrounds without a dark container
- Never stretch or distort
- Never add drop shadows or outer glows to the logo itself
- Never change the logo colors outside the approved palette
- Never rotate the logo

## 3. Color System

### Primary Palette
```
Deep Space     #0A0E17  — Primary background
Midnight Steel #131A2B  — Cards, panels, elevated surfaces
Electric Cyan  #00E5FF  — Primary accent, CTAs, links
Neon Green     #39FF14  — Terminal/success, secondary accent
```

### Neutral Palette
```
Cloud White    #E8ECF1  — Primary text
Slate Gray     #64748B  — Secondary text, captions
Steel Edge     #1E293B  — Borders, dividers
```

### Semantic Colors
```
Amber Pulse    #FFAB00  — Warnings, highlights
Signal Red     #FF3B5C  — Errors, critical states
```

### Usage Rules
- Electric Cyan is the dominant accent — use it for all primary interactive elements
- Neon Green is reserved for terminal/code contexts and success states
- Never use Cyan and Green adjacent without sufficient spacing
- Maintain WCAG AA contrast ratios (4.5:1 for text, 3:1 for large text)

## 4. Typography

### Font Hierarchy
| Role         | Font             | Weight        | Fallback          |
|--------------|------------------|---------------|-------------------|
| Display/H1   | JetBrains Mono   | Bold (700)    | monospace          |
| Headings     | Inter            | SemiBold (600)| system-ui, sans    |
| Body         | Inter            | Regular (400) | system-ui, sans    |
| Code/Terminal| Fira Code        | Regular (400) | monospace          |

### Rules
- JetBrains Mono is for brand name, hero text, and section titles only — never for body copy
- Inter handles all readable text
- Fira Code is exclusively for code blocks, tags, and terminal-styled elements
- Minimum body text size: 16px (web), 14px (mobile)

## 5. Imagery & Visual Language

### Photography
- Dark, moody lighting with cyan/blue accent tones
- Server rooms, monitors, terminal screens as contextual backgrounds
- Professional headshots with subtle tech lighting

### Illustrations & Icons
- Line-style icons, 2px stroke, rounded line caps
- Recommended: Lucide Icons or Phosphor Icons
- Primary icon color: Electric Cyan
- Secondary icon color: Slate Gray

### Backgrounds
- Subtle grid patterns (60px spacing, 30% opacity)
- Radial cyan glow effects behind focal points
- Dot-matrix network node patterns for section breaks

### Code Blocks
- Always styled as terminal windows with red/yellow/green dots
- Background: Midnight Steel (#131A2B)
- Border: Steel Edge (#1E293B)
- Text: Neon Green (#39FF14) for commands, Slate Gray for output

## 6. Voice & Tone

### Brand Personality
| Trait          | Expression                                          |
|----------------|-----------------------------------------------------|
| **Direct**     | No fluff. Clear and concise like good documentation. |
| **Confident**  | Speaks with authority from real experience.          |
| **Technical**  | Uses precise terminology. Doesn't dumb things down. |
| **Human**      | Warm and approachable despite the technical depth.   |

### Writing Guidelines
- Active voice, always ("I built" not "it was built")
- Lead with outcomes and metrics ("Reduced deploy time by 80%")
- Short paragraphs (3-4 sentences max)
- Use `>` or `->` as bullet markers in social content (matches terminal aesthetic)
- Avoid: "passionate about", "synergy", "leverage", "guru", "ninja"

### Tone by Context
| Context        | Tone                                                |
|----------------|-----------------------------------------------------|
| Portfolio      | Professional, confident, outcome-focused            |
| LinkedIn       | Authoritative but approachable, story-driven        |
| Twitter        | Punchy, opinionated, technical wit                  |
| GitHub         | Precise, documentation-style, helpful               |
| Email/DMs      | Friendly, direct, professional                      |
